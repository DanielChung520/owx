# ISO/IEC/IEEE 29148:2018（ISO-IEC-IEEE-29148）

> 收錄形式：summary＋自撰綱要　|　授權：proprietary　|　可收錄全文：否　|　分類：系統／軟體工程（SRS 參考規範）
> 版本：v0.1　|　日期：2026-10-20　|　狀態：Draft　|　內容性質：**自撰**（非標準原文）
> 來源：https://www.iso.org/standard/72089.html

## 摘要
系統與軟體需求工程之生命週期流程與資訊項目；定義「好的需求」之建構、屬性與特性，並規定 SRS 之內容與格式（取代 IEEE 830）。

## 適用範圍
- 進行需求工程之團隊；無論專案範疇、方法、規模。**owx 之文件撰寫核心參考**。

## 自撰檢核綱要（供自評；**非標準原文**）
**需求流程**
- [ ] 需求引出（elicitation）與來源識別
- [ ] 需求分析與規格化
- [ ] 需求驗證（validation）與確認
- [ ] 需求管理（基線、變更控制、追溯）

**SRS 文件大綱（常見結構）**
- [ ] 1 簡介：目的、範疇、定義、參考文件、綜覽
- [ ] 2 整體描述：產品觀點、功能、使用者特性、限制、假設與相依性
- [ ] 3 特定需求：外部介面、功能、效能、資料庫、設計限制、系統屬性

**需求品質特性（單一需求應具備）**
- [ ] 必要（necessary）　- [ ] 適切（appropriate）
- [ ] 無歧義（unambiguous）　- [ ] 完整（complete）
- [ ] 單一（singular）　- [ ] 可行（feasible）
- [ ] 可驗證（verifiable）　- [ ] 正確（correct）
- [ ] 符合（conforming）　- [ ] 可追溯（traceable）
